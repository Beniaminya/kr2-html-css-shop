# Зелёный дом

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

«Зелёный дом» — учебный многостраничный сайт интернет-магазина комнатных растений. Проект продолжает содержание контрольной работы №1: сохранены тематика, товары, тексты, изображения и вымышленные контактные данные. Интерфейс переработан с использованием Bootstrap.

## Используемый фреймворк

В проекте используется Bootstrap 5.3.8.

Bootstrap подключён локально, поэтому страницы работают без доступа к CDN:

- `vendor/bootstrap/css/bootstrap.min.css` — стили Bootstrap;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript Bootstrap вместе с Popper;
- `css/custom.css` — собственные стили проекта, подключённые после Bootstrap.

## Структура проекта

- `index.html` — главная страница с hero-блоком, преимуществами, популярными товарами и accordion;
- `catalog.html` — каталог с адаптивной сеткой, фильтрами и pagination;
- `product.html` — страница монстеры с описанием, tabs и таблицей характеристик;
- `order.html` — форма заявки на Bootstrap-компонентах;
- `contacts.html` — дополнительная страница с контактами и формой обратной связи;
- `css/custom.css` — фирменные цвета и точечные настройки поверх Bootstrap;
- `js/main.js` — валидация форм, заполнение модального окна и фильтрация каталога;
- `images/` — локальные изображения товаров;
- `vendor/bootstrap/` — локальные файлы Bootstrap.

## Реализованные компоненты Bootstrap

- адаптивная навигация `navbar` и раскрывающееся мобильное меню `collapse`;
- сетка `container`, `row`, `col-*`, `row-cols-*` и отступы `g-*`;
- карточки `card`;
- кнопки `btn`;
- метки товаров `badge`;
- сообщения `alert`;
- модальное окно `modal`;
- поля `form-control`, списки `form-select`, группы `input-group` и флажки `form-check`;
- хлебные крошки `breadcrumb`;
- вкладки `tabs` на странице товара;
- раскрывающийся блок `accordion` на главной странице;
- постраничная навигация `pagination` в каталоге;
- адаптивная таблица `table-responsive`.

## Самостоятельные доработки

- Bootstrap подключён локально без CDN;
- сохранён единый стиль и содержание первой контрольной работы;
- добавлена дополнительная страница контактов;
- реализована работающая фильтрация каталога по названию, категории и цене;
- выбранный товар автоматически подставляется в форму быстрого заказа;
- формы используют HTML-валидацию и визуальные состояния Bootstrap;
- после корректного заполнения формы появляется сообщение об успехе;
- добавлены tabs, accordion, pagination и breadcrumb;
- улучшена адаптивность для телефонов, планшетов и широких экранов;
- футер прижат к нижней части коротких страниц через Flexbox.

## Как открыть проект

1. Откройте папку `kr2-html-css-shop` в Visual Studio Code.
2. Откройте `index.html` в браузере или запустите расширение Live Server.
3. Перейдите между страницами с помощью меню.

Сборка проекта и установка зависимостей не требуются.

## Как проверить работу

1. Уменьшите ширину окна: меню должно превратиться в кнопку и раскрываться по нажатию.
2. На главной странице откройте accordion и модальное окно заказа.
3. В каталоге измените строку поиска, категорию и максимальную цену.
4. На странице товара переключите вкладки «Описание», «Уход» и «Доставка».
5. Попробуйте отправить пустую форму — Bootstrap покажет ошибки.
6. Заполните обязательные поля — появится сообщение об успешной демонстрационной отправке.

## Кратко для защиты

- `container` ограничивает ширину содержимого и добавляет боковые отступы.
- `row` создаёт строку Bootstrap-сетки, а `col-*` задаёт колонки на разных ширинах экрана.
- `g-*` отвечает за промежутки между колонками и строками.
- `navbar` создаёт навигацию, а Bootstrap JS Bundle обеспечивает раскрытие мобильного меню.
- `card` используется для карточек товаров и информационных блоков.
- `modal` показывает диалог поверх страницы.
- `custom.css` подключён после Bootstrap, чтобы собственные правила могли уточнять стандартные стили.
- Локальное подключение позволяет открыть проект без интернета и показывает структуру внешней библиотеки.
